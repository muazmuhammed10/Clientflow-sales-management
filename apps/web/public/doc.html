1. System Introduction & Product Vision

ClientFlow is an enterprise-grade Customer Relationship Management (CRM) and Sales Management application engineered for modern B2B sales teams. It unifies lead acquisition, qualification workflows, account directories, visual drag-and-drop sales pipelines, team deliverables, and revenue analytics into a single cohesive platform.

Key Business Objectives:

  • Lead Management & Qualification: Capture incoming leads, prioritize prospects, detect duplicate records, and convert qualified leads into customer accounts with a single click.
  • Visual Sales Pipeline: Manage opportunity stages with an optimistic-update Kanban board.
  • Account Governance: Maintain structured directories for Customer Contacts and Target Company Accounts.
  • Team Collaboration: Assign tasks, track follow-up deadlines, and enforce multi-tenant Role-Based Access Control (RBAC).
  • Executive Intelligence: Live database metrics, Win Rate tracking, Weighted Revenue Forecasting, and sanitized CSV data exports.

2. Architecture & Technology Stack

Built with a production-minded type-safe stack designed for performance, scaling, and operational predictability.

Layer Technology Selected Purpose
Frontend React 18 + TypeScript + Vite 5 High-performance single-page interface
Styling Tailwind CSS (Obsidian Executive Theme) Custom B2B SaaS dark theme aesthetic
State & Data TanStack React Query v5 Server state management, caching & optimistic updates
Backend API Node.js + Express.js (TypeScript) RESTful API layer with Zod validation
Database & ORM PostgreSQL + Prisma ORM Relational data persistence with multi-tenant scoping
Security JWT + Argon2id / bcrypt Secure auth tokens, password hashing & rate limiting
